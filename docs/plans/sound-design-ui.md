# SOUND DESIGN UI

The Sound Design UI should have 
- panels in a horizontal view
- dial settings with MIDI Learn functionality
- each dial can accept also input with keyboard for numeric values
- the theme color palette should composed of following colors: 
#FAF8F2 (main theme color) #E9E2D0 #D7C7B8 #C7D7D4 #B9C7D6 

## Panels layout
- Top Bar: Logo - Performance - Sound Design - Bank Selector - Current Patch - Master Volume - Panic

- WorkArea

## Sound Design Layout

The Sound Design should be also possible on the current system bank patche, not only on the new bank/patches.

### Workarea Layout Structure
Left Pane: Bank Selector > Presets List
Main panel: 
    - Layers Tab (Layer selector)
        - Layer Params Panel
        - Layer Zones
        - Zone Assignment add a full mini keyboard where the user can assign the zone range clicking on the corrispondent note (show the current settings also in the mini keyboard). Button to show the dials layer
    - Filter Tab
        - Filter Type
        - Filter Envelope (drawing mode): with a button open a layer with the dials. By default the filter envelope is in envelope drawing mode
    - Envelope Tab
        - Envelope (drawing mode): with a button open a layer with dials.
    - Aux Tab
        - Envelope (drawing mode): with a button open a layer with dials.
    - LFOs Tab
        - LFO1 and LFO2 settings
    - MOD/MATRIX TAB
        - add a custom MIDI CC to each MOD/MATRIX
